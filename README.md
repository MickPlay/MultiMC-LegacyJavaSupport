# MultiMC Java 6 Fork

✅ A fork of MultiMC (0.7.x) with restored **Java 6** support  
🎮 Allows launching older versions of Minecraft (up to 1.11.2) with original Java 6 compatibility  
🛠 Based on the official MultiMC version

## Differences from the original

- Minimal changes to enable compatibility with **Java 6**.
- Fixed `OneSixLauncher.java` to compile correctly with `-source 1.6`.
- No changes to the rest of the code — all other functionality matches MultiMC 0.7.x.

## Why is this useful?

Some older Minecraft mods and versions (such as 1.5.2 to 1.11.2) require **Java 6**.  
Modern versions of MultiMC have dropped Java 6 support, so this fork is useful for running legacy projects, archival servers, or for testing purposes.

## Usage

Build the project the same way as the original MultiMC.
